# DART Tutorial Slides

This repository hosts the PDF versions of tutorial slides for the [Data Assimilation Research Testbed (DART)](https://dart.ucar.edu).


The github pages gets built using the contents of the docs directory.  
The website is live at: https://ncar.github.io/dart-tutorial/

You can add whatever you want to the repo **outside** the docs folder.  
If you want to change what is on the website: https://ncar.github.io/dart-tutorial/ changes the docs folder.
